## SAP

SAP Help URLs vary by release and product. Prefer release-specific SAP Help Portal documentation and the system's DDIC metadata over third-party table catalogs.

Useful official starting points:

- SAP Help Portal: https://help.sap.com/
- SAP Community for implementation discussions: https://community.sap.com/

Validate:

- ECC versus S/4 persistence changes;
- released CDS/API recommendations;
- DDIC data element/domain definitions;
- currency and unit reference fields;
- pricing procedure configuration;
- Universal Journal semantics;
- material-document and pricing persistence changes.
