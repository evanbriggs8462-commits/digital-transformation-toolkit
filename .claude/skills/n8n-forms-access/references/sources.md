# Sources

Checked 2026-10-12. These describe current documentation; verify installed Cloud and node versions before generating workflow JSON.

- [n8n Form Trigger](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.formtrigger): authentication, authenticated user output, form styling, sanitization, test/production URLs.
- [n8n SAML](https://docs.n8n.io/administer/manage-users-and-access/verify-user-identity/use-saml.md): instance SSO setup and plan availability.
- [n8n Webhook](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.webhook): Basic/Header/JWT authentication and request/response configuration.
- [OWASP Authorization](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html): deny by default, least privilege, server-side checks on every request.

The tracker schemas, gateway design, receipt workflow, and test cases are application design recommendations, not built-in n8n features.
